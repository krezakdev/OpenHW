


# OpenHW

OpenHW is an opensource HappyWheels desktop Client  for linux and mac,(although we may 
support windows and chromeOS in the future) OpenHW is also based on openwheels by jargdev,
which is also here on github and we'll link the OpenWheels repository here,

## openWheels
Is a reobfuscated open source copy of Happy Wheels that you can check out [here](https://github.com/jargdev/openWheels)
